# To-Do List (Tailwind CSS + vanilla JS)

**Автор:** Сергей, ФИТ-241

Tailwind-версия приложения To-Do List: добавление через модальное окно, редактирование, удаление, отметка выполненных, поиск, сохранение в `localStorage`. Переключение темы не переносилось. Интерфейс адаптивный и доступный (A1–A7). Стили написаны только утилитами Tailwind CSS v4, собственных CSS-правил нет.

## Установка и сборка

```bash
npm install
npm run build        # src/input.css -> dist/css/main.css
```

## Запуск при разработке

В двух терминалах:

```bash
npm run tailwind:dev # пересборка стилей при изменениях
npx serve .          # локальный сервер, затем открыть http://localhost:3000
```
