# To-Do List (Sass + vanilla JS)

**Автор:** Сергей, ФИТ-241

Приложение для управления задачами: добавление через модальное окно, редактирование, удаление, отметка выполненных, поиск по названию, светлая и тёмная темы. Задачи и тема сохраняются в `localStorage`. Интерфейс адаптивный и доступный (требования A1–A7: клавиатура, доступные имена кнопок, `<dialog>`, управление фокусом, контраст ≥ 4.5:1).

## Установка и сборка

```bash
npm install
npm run build        # scss -> dist/css/main.css
```

## Запуск при разработке

В двух терминалах:

```bash
npm run sass:dev     # пересборка стилей при изменениях
npx serve .          # локальный сервер, затем открыть http://localhost:3000
```

## Структура

`scss/` — `utils` (переменные, миксины), `base`, `layout`, `components` (БЭМ), `themes` (CSS custom properties); `js/main.js` — логика.
